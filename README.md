# DC Mobilya Üretim

Mobilya ustaları için ölçüden teklife, malzeme listesinden fason kesim listesine kadar her şeyi hazırlayan, internetsiz çalışan (PWA) web / mobil uygulama.

- Kullanım kılavuzu, hesap kuralları ve geliştirme günlüğü: **[KITAP.md](KITAP.md)**
- Çalıştırma: `npm install && npm run dev` · Test: `npm test` · Derleme: `npm run build`
